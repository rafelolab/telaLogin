# Login Page | Tela de Login

A login interface built with HTML and CSS, featuring a clean layout, email and password fields, and additional account-related options.

Uma interface de login desenvolvida com HTML e CSS, com campos de e-mail e senha e opções relacionadas ao acesso e à conta do usuário.

## Features | Recursos

- Email and password input fields.
- "Remember me" checkbox.
- Password recovery and account registration links.
- Icons provided by Font Awesome.

- Campos para e-mail e senha.
- Caixa de seleção "Lembrar-me".
- Links para recuperação de senha e cadastro.
- Ícones fornecidos pelo Font Awesome.

## Technologies | Tecnologias

- HTML5
- CSS3
- Font Awesome 6

## Getting Started | Como executar

1. Clone this repository:

   ```bash
   git clone https://github.com/rafelolab/telaLogin.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.
